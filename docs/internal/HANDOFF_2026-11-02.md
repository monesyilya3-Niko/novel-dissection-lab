### 3.2 题材隔离（铁律一）的真实实现

题材标识**不在** `meta.genre` 上（大多数资产没有这个字段）。规则在
`gui/asset_index._genre_from_file` 与 `gui/writing_service._asset_genre`（两处独立实现，避免循环 import）：

```python
meta.genre          # 优先
meta.id 的 "genre-" 前缀   # 回退，题材包/文风卡都靠这条
```

所以 `campus-redemption-genre-pack.json` 的 `meta.id = "genre-campus-redemption"`，
API 返回 `genre: "campus-redemption"` —— 前端排序与预检都吃这个值。

后端强制点在 `writing_service._require_genre_match`（`gui/writing_service.py:130`）：声线卡题材与任一已选资产题材**都已知且不同** → 400。任一侧未知放行（历史资产兼容）。`prose_card` 豁免。
